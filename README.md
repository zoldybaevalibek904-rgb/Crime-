# CRIME DISTRICT · Alpha 0.2.2

Офлайн-игра для Java ME MIDP 2.0 / CLDC 1.1. Downtown занимает
768×704 пикселя при размере тайла 16×16. Игровой экран рассчитан на 240×320
в портретной ориентации.

## Запуск

Скачайте `CrimeDistrict_Alpha022.jar` и `CrimeDistrict_Alpha022.jad` из
GitHub Actions artifact `crime-district-alpha022` или из каталога `dist/`
в ветке `work`. Храните JAD и JAR рядом под исходными именами.
В J2ME Loader импортируйте MIDlet и выберите портретный экран 240×320.

| Кнопка | Пешком | В седане |
| --- | --- | --- |
| 2 / ↑ | Вверх | Вверх |
| 8 / ↓ | Вниз | Вниз |
| 4 / ← | Влево | Влево |
| 6 / → | Вправо | Вправо |
| 5 / Fire | Сесть в седан | Выйти на малой скорости |
| Левая софт-клавиша | Пауза | Пауза |
| Правая софт-клавиша | Назад / пауза | Назад / пауза |

В миссии «Первая доставка» (First Delivery) сначала доберитесь пешком до отметки рядом с парковкой. Затем сядьте в сине-серый седан и доедьте до второй отметки. После доставки можно свободно ездить по району. Такси, SUV и фургон принадлежат дорожному трафику. В районе ходят шесть пешеходов со своими маршрутами, одеждой и аксессуарами.

## Сборка и проверка

Запустите `tools/build.sh` с Java 21, Python 3 и curl. Скрипт скачивает
зафиксированные версии ECJ, API MicroEmulator CLDC/MIDP и ProGuard из
Maven Central, компилирует Java 1.4, выполняет CLDC preverification и
проверяет пакет. Результат находится в `dist/`.

После сборки `tools/test-model.sh` запускает проверку модели из готового JAR. Она покрывает движение, нормализацию диагоналей, препятствия, все маршруты ИИ и прохождение задания обычным вводом. Сценарий выполняет 14 400 тиков уличной симуляции.

PNG и карта включены в репозиторий. Сборка игры использует готовые атласы.
Для обновления графики на этапе разработки нужен Pillow 12+.

- `python3 tools/art.py` пересобирает фон, объекты окружения и карту.
- `python3 tools/actor_art.py path/to/reference.png` пересобирает атласы персонажей и машин из приложенного листа 1536×1024. Скрипт использует заданные области, общую для кадров опорную линию, локальную выборку пикселей, удаление фона и правки на игровой сетке. Исходный презентационный лист нужен только для регенерации.

У каждого персонажа атлас 96×144, кадр 24×36. Столбцы идут в порядке
Idle, Walk A, Walk B, Walk C. Строки идут в порядке UP, DOWN, LEFT, RIGHT.
Цикл воспроизводит A → B → C → B. Атласы машин используют ту же
последовательность направлений по столбцам. Игровые атласы актёров используют
индексированные PNG с прозрачностью.

Рабочий процесс **Build Java ME** запускается при push, pull request или
вручную через **Actions → Build Java ME → Run workflow**.
