# CRIME DISTRICT · Alpha 0.5

Игра для Java ME MIDP 2.0 / CLDC 1.1. Экран 240×320, портретная ориентация.
MIDlet запускается через `crimedistrict.CrimeDistrict`.

[Графика Alpha 0.4 и 0.5, фазы анимации](docs/alpha05-art.png) · [Кадры игрового процесса](docs/alpha05-gameplay.png) · [Аудит Alpha 0.4 и проверка изменений](docs/alpha05-audit.md)

## Запуск

Скачайте `CrimeDistrict_Alpha05.jar` и `CrimeDistrict_Alpha05.jad` из артефакта
`crime-district-alpha05` или каталога `dist/` ветки `work`. Храните файлы рядом
под исходными именами. В J2ME Loader используйте разрешение 240×320.

| Кнопка | Действие |
| --- | --- |
| 2, 4, 6, 8 / стрелки | Движение и вождение |
| Быстрое двойное нажатие направления | Бег, пока направление удерживается |
| 5 / Fire | Пешком подбирает предмет, затем проверяет машину, дверь или NPC. В свободном контексте атакует |
| 5 / Fire за рулём | Выходит из машины на малой скорости |
| 1 | Автомобильный сигнал |
| 3 | Свободная кнопка |
| * | Следующее имеющееся оружие |
| 9 | Перезарядка |
| 0 | Инвентарь и аптечка |
| # | Мини-карта |
| Софт-клавиши | Пауза и возврат |

## Город

Карта Alpha 0.4 сохранена. Из стартовой точки доступны 28 363 центра клеток.
У дверей есть подсказки для входа в Market, гараж, оружейный магазин, кафе
и убежище. В помещениях можно дойти до стойки и взаимодействовать с ней.
Возвращайтесь к той же двери для выхода. Убежище находится в Residential
и восстанавливает здоровье возле интерактивной точки.

На улицах появляются Sedan, Taxi, SUV, Van, Pickup, Sports Coupe, Muscle Car,
Luxury Sedan, Police Cruiser и Ambulance. Восемь гражданских машин
можно купить в гараже. Новые машины используют собственные характеристики.
На четырёх звёздах подключается вертолёт, на пяти может выехать один танк.
Наземные машины следуют дорожным маршрутам.

В Market и гараже можно купить магазин и автомастерскую соответственно.
Их доход поступает в кассу во время игры. Касса ограничена $160, деньги
забираются через меню владельца. HUD показывает здоровье, деньги, боезапас,
прочность машины и цель. Мини-карта помечает больницу, гараж, убежище, цель
и приобретённый бизнес.

Сохранены 11 прежних миссий. Новые задания с 12 по 17 ведут от знакомства
с брокером до финального преследования и возвращения в убежище. Повторяемые
занятия включают Taxi Job, Delivery Job, Checkpoint Race, курьерскую доставку,
доставку автомобиля и Coastal Sprint.

## Сохранения

`CONTINUE` читает сохранения Alpha 0.3 и 0.4 и переносит их в новый формат
RecordStore. Версия 3 добавляет интерьер и локальные координаты, аптечки,
миссионный груз, купленные бизнесы и отношения с бандами. Позиции трафика,
вызовы EMS и оставленные на земле предметы восстанавливаются как состояние
новой сессии. Собранные деньги, оружие и боеприпасы сохранены.

## Сборка

`tools/build.sh` требует Java 21, Python 3 и curl. Он компилирует Java 1.4
против API MIDP/CLDC, выполняет CLDC preverification и проверяет ресурсы,
манифест и поля JAD. `tools/test-model.sh` запускает проверки модели из
собранного JAR.

Готовые PNG и карта входят в репозиторий. Для регенерации ресурсов Alpha 0.5
из текущих исходных атласов нужны Pillow 12+ и команды
`python3 tools/animation05.py` и `python3 tools/world05.py`.
