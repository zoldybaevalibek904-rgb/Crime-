# CRIME DISTRICT · Alpha 0.3 Expanded

Офлайн-игра для Java ME MIDP 2.0 / CLDC 1.1. Четыре района на одной карте
1536×1408 пикселей. Игровой экран рассчитан на 240×320 в портретной ориентации.

## Запуск

Скачайте `CrimeDistrict_Alpha03.jar` и `CrimeDistrict_Alpha03.jad` из
GitHub Actions artifact `crime-district-alpha03` или из каталога `dist/`
ветки `work`. Храните JAD и JAR рядом под исходными именами.

| Кнопка | Пешком | За рулём |
| --- | --- | --- |
| 2 / ↑ | Вверх | Вверх |
| 8 / ↓ | Вниз | Вниз |
| 4 / ← | Влево | Влево |
| 6 / → | Вправо | Вправо |
| 5 / Fire | Сесть в ближайшую доступную машину | Выйти на малой скорости |
| Левая софт-клавиша | Пауза | Пауза |
| Правая софт-клавиша | Назад / пауза | Назад / пауза |

Достаточно подойти к припаркованной машине или к машине трафика, чтобы появилась
подсказка. Захват машины трафика и столкновение с полицейским автомобилем повышают
розыск. Полицейские машины остаются транспортом патрулей. Уезжайте из зоны
преследования и пропадите из поля зрения, чтобы розыск постепенно снизился.

Миссии открываются по порядку: «Первая доставка», «Новая работа», «Срочный груз»,
«Нежелательное внимание», «Чужая территория», «Дорога к побережью».
Маркер на краю экрана показывает направление к цели. Прогресс и координаты
сохраняются в RecordStore при смене цели, постановке на паузу и периодически
во время игры. `CONTINUE` восстанавливает игрока и машины, которыми он пользовался.
Новая игра создаёт новую точку сохранения. В Alpha 0.2.x формата сохранений ещё не было.

## Сборка и проверка

Запустите `tools/build.sh` с Java 21, Python 3 и curl. Скрипт скачивает
зафиксированные версии ECJ, API CLDC/MIDP и ProGuard, компилирует Java 1.4, выполняет
CLDC preverification и проверяет пакет. Затем `tools/test-model.sh` запускает
регрессионный тест из готового JAR: геометрию, проезды между районами, 14 500 тиков
маршрутов, четыре типа машин, розыск, шесть заданий и формат сохранения.

PNG и карта включены в репозиторий. Для их обновления нужен Pillow 12+.

- `python3 tools/art.py` регенерирует исходный Downtown и его декорации.
- `python3 tools/world_art.py` строит объединённую карту, расширенный атлас поверхности и новые здания и декорации.
- `python3 tools/actor_art.py path/to/reference.png` регенерирует героя, исходных прохожих и четыре гражданские машины из художественного листа 1536×1024.
- `python3 tools/city_people.py` рисует варианты одежды, формы и экипировки для новых групп и собирает полицейскую машину на игровой сетке.

Карта и зоны занимают 16,5 КиБ как два массива байтов. Проверка статических
коллизий использует списки препятствий по полосам высотой 64 пикселя. Далёкие
объекты обновляются реже, атласы прохожих загружаются по видимости.

Рабочий процесс **Build Java ME** запускается при push, pull request или
вручную через **Actions → Build Java ME → Run workflow**.
